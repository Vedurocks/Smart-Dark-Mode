Overview

This is a smart dark-mode extension designed to enhance your browsing experience. Unlike basic toggles, it analyzes each website and applies dark mode automatically or with customization based on your preferences.

Features

✅ Automatic Dark Mode: Applies dark mode per website intelligently.

✅ Non-blocking AI-style Popup: Transparent loading animation (8–20s) while analyzing the page.

✅ Custom Preferences: Always dark, never dark, or manual adjustment for specific sites.

✅ Element Removal: Hide page elements that break in dark mode.

✅ Memory: Remembers your choices and auto-applies in future visits.

✅ Future AI Enhancements: Plans for color, contrast, and layout fixes for natural dark mode.

Installation

Clone the repository:

git clone https://github.com/vedurocks/smart-dark-mode.git


Load the extension in your browser (Chrome/Edge/Brave) via chrome://extensions → Load unpacked.

Enjoy smart dark mode!

Usage

Click the extension icon.

Watch the AI-style loader analyze the page.

Dark mode is applied automatically or based on your saved settings.
